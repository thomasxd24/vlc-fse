Foyer - Full screen experience package
======================================

EN  Double-click Install-Foyer-FSE.cmd and accept the admin prompt.
    It installs Foyer as a "Full screen experience" home app and can set it as the home app.
    Afterwards: Settings > Gaming > Full screen experience > Home app > Foyer.
    To remove it, run Uninstall-Foyer-FSE.ps1 (right-click > Run with PowerShell).

    Developer Mode is switched on only while installing (Windows requires it for the home-app
    capability of a package not from the Store) and restored afterwards.

FR  Double-cliquez sur Install-Foyer-FSE.cmd et acceptez la demande administrateur.
    Foyer est installé comme application d'accueil de l'« Expérience plein écran ».
    Ensuite : Paramètres > Jeux > Expérience plein écran > Application d'accueil > Foyer.
    Pour le retirer : Uninstall-Foyer-FSE.ps1 (clic droit > Exécuter avec PowerShell).

    Le mode développeur n'est activé que pendant l'installation, puis remis comme avant.
